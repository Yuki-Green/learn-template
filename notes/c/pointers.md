# 指针 (Pointers)

> 学习日期：{{DATE}} — 状态：进行中

## 核心概念

- 指针是**存储地址的变量**：`int *p` 表示 p 指向 int。
- `&x` 取地址；`*p` 解引用（取 p 指向的值）。
- 指针算术：`p+1` 实际地址增加 `sizeof(所指向类型)`。

## 示例

```c
int a = 10;
int *p = &a;
printf("a=%d, *p=%d, p=%p\n", a, *p, (void*)p);
```
